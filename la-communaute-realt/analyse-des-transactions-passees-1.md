# Historique de vos achats sur le second marché

Les achats sur le marché primaire (site RealT, lors du lancement) font l'objet de factures : la tracabilité est donc assez simple.\
Pour les achats sur le marché secondaire (YAM et swapcatt), il n'y a pas de facture, juste un enregistrement sur la blockchain.\
\
Si vous n'avez pas noté la valeur d'un achat sur le marché secondaire (information qui est demandé lors de la déclaration de cession), ce genre de site qui va lire la blockchain pour votre wallet est bien utile ...

### Site Ehpst

[https://ehpst.duckdns.org/realt\_rent\_tracker/holder](https://ehpst.duckdns.org/realt_rent_tracker/holder)\
\
Après avoir indiqué le wallet dans My Stuff, choississez l'historique, ne mettez aucune adresse et vous aurez tous les achats du wallet
